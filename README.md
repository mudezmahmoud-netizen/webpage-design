# PraRoz Webpage Design (Capstone Project)

A responsive, modern web application designed for a technology training center. The platform provides structured course layouts, responsive menu navigation, and an intuitive user interface to accommodate everyone's self-development needs and maximize learning expectations.

##  Features

*   **Responsive Navigation (`.navbar`):** Fully integrated logo brand styling with dynamic links connecting structural pages (Home, About, Services, Design, Contact).
*   **Dynamic Hero Showcase (`.content`):** Clean, typography-focused hero layout highlighting core tracks in Technology Design & Development courses.
*   **Interactive Input Modules (`.form`):** A landing portal structured for student course registrations, inquiries, or customized client intake.
*   **Modular Styling Hierarchy:** Explicitly maps structural components to localized aesthetic rules maintained via a centralized stylesheet sheet.

##  Built With

*   **HTML5:** Semantic architecture (`<nav>`, `<ul>`, `<li>`, `<h1>`, etc.) ensuring accessible content parsing.
*   **CSS3:** Cascading style system (`style.css`) handling layouts, alignment, flex components, and responsive display triggers.

##  Project Architecture

```text
├── index.html        # Main landing grid containing structural layouts
└── style.css         # Typography, aesthetic behaviors, and layout configurations
```

##  Getting Started

Follow these steps to run a local copy of this project on your device.

### Prerequisites

Ensure you have a modern web browser installed (e.g., Google Chrome, Mozilla Firefox, Microsoft Edge) along with a code text editor like Visual Studio Code.

### Installation & Execution

1. **Clone the Repository**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the Project Root**
   ```bash
   cd praroz-webpage-design
   ```
3. **Launch the Application**
   * Double-click the `index.html` file inside your file explorer, OR
   * Right-click `index.html` in VS Code and select **Open with Live Server**.
